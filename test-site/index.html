WASM test workloads

Looped workloads run repeatedly for ~2 seconds; the benchmark runs once. Start the profiler from the extension popup first, run a workload, then stop the profiler.

Every module is compiled from real source inside the test-site container: Rust for the recursion / loop / chain shapes, C++ for the multi-value return. The release and debug builds are separate modules with different function index spaces — profile one and symbolize it with the other.
